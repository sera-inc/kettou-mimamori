# UIチェックリストのレビュー記録

2026-10-13。対象は血糖みまもりのブラウザUIと企業サイトの製品LP。参照はデジタル庁の[UIチェックリスト](https://www.digital.go.jp/assets/contents/node/basic_page/field_ref_resources/e2a06143-ed29-4f1d-9c31-0f06fca67afc/860f1eec/20251016_ui_checklist.xlsx)（[掲載ページ](https://www.digital.go.jp/resources/standard_guidelines)）。取得した原本のSHA-256は `137b73188f7b1acb9c61428454cf6f633de47953976b324e0a5e4988e442a338`。原本には同じ番号3.1.2の2項目、廃止項目6.2.4があり、番号だけで一意と扱わない。

| 確認対象 | 結果・証跡 |
| --- | --- |
| スマートフォン、一貫した表示・用語 | 390pxとPCで主要画面、51状態、11レポートを確認。DDSのトークン原本を保持し、表示用の対応表を固定。日本語辞書の識別子と値の差を厳密逆変換。人間によるデザイン承認あり。 |
| 利用条件、必要な環境、説明と問い合わせ | LPの導入条件、機器・保存先・共有範囲・運用の確認事項、用語を展開した機能説明、常設の株式会社世良・info@sera-inc.co.jpへの導線を確認。電子申請の資格・必要書類・受付曜日は対象外。 |
| 認証、本人情報 | ブラウザのAPI秘密情報・権限確認を維持。認証のローカル保存形式は新旧を実通信で確認。電子署名、メール所有確認、CAPTCHA、住所・性別・法人番号を収集する申請フォームは対象外。API秘密情報の検証規則はデザイン変更で置き換えない。 |
| 日付、選択肢、再利用、途中保存 | 日付・時刻の直接入力と選択、既存の初期値、食品の定型セット、プロフィールの保存と再読込みを確認。未保存フォームの再読込みによる破棄まで新たな下書き保存機能として提供するものではない。既存の保存契約を維持。 |
| ブックマーク、入力中のフォーカス | 主要経路とAPI説明の独立した操作リンク、プロフィールの時間帯追加・削除と食品の並べ替え後のフォーカスを確認。元の値・入力要素・ハンドラを移植せず保持。 |
| 動きと制限時間 | LPの動画は操作による再生・停止、日本語字幕、音声なし。定期更新する血糖表示は業務データであり装飾アニメーションと区別。ブラウザの入力完了にセッション制限時間を新設しない。API v3のJWT期限をブラウザのフォーム期限と混同しない。 |
| タップ、キーボード、ダイアログ | DDSの44pxの操作領域、可視フォーカス、スキップリンク、メニュー・タブ・ダイアログのネイティブ操作とフォーカス復帰を確認。食品のドラッグ代替は既存のdrop/sortコールバックを呼び出し、ポインター操作も保持。 |
| コピー、入力と通知 | コードのスクロールとコピーの名前を付与。入力値やコード例を表示翻訳で書き換えない。重要な警報・測定の古さを一時的なToastへ移さず、既存の状態表示を保持。 |
| 保存・削除とエラー | 合成DBで食品・治療・プロフィール・利用者・権限のCRUDと拒否を確認。管理の期間・未来記録の削除は検証で作った対象だけに限定し、対象外コレクションの全件SHAを照合。既存のAPIスキーマ・数値の許容範囲を勝手に変更しない。既存の汎用エラー表示を項目別バリデーションの完全適合とは宣言しない。 |
| サイズ、コントラスト、区別 | 文字サイズ、各図とAPI説明のコントラスト、下線・枠・アイコン、横はみ出しを確認。血糖・予測の色は表示境界で変換し、元の数値・系列・座標と照合。色だけに依存せず値・ラベル・方向を保持。 |
| 見出し、ラベル、処理中 | 既存のフォームに用途をレビューした名前を与え、ネイティブlabelを優先。DataGridの見出しとcaption、Skeleton、保存の状態表示、空状態を確認。必須・任意、入力制約は既存の保存モデルに従い、行政申請の新たな必須項目を追加しない。 |
| 支援技術 | ユーザーが動的な血糖表示・表・設定ダイアログについて「確認済みで問題なし」と回答。実施した支援技術名・版の詳細は未取得。自動axeの結果と混ぜない。 |

レビューゲートとして参照し、対象外と互換性上の差を記録した。行政申請向け全項目への適合認証や、未検証の実機・音声・外部センサー連携まで完了したという主張はしない。既存のjQuery/D3、フォームの保存契約、医療数値の処理を維持する移行方針は `deviations.md` を参照。
