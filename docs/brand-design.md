# 血糖みまもりのブランド

サービス名は「血糖みまもり」、リポジトリ名は `kettou-mimamori`。
株式会社世良が提供し、問い合わせは info@sera-inc.co.jp。

デジタル庁のデザイン資料と同梱したDADSのトークンを参考に、読みやすい文字、明確なコントラスト、簡潔な線画を採用した。シンボルは血糖を表す滴と推移の線を組み合わせた独自のSVGであり、政府のロゴ・紋章を使用しない。

- `static/brand/mark.svg`：滴と推移の独自シンボル。
- `static/brand/logo.svg`：サービス名を含むロゴ。
- `static/brand/icons/`：独自の24種類の線画。既存のクラスと操作ハンドラーは保持し、マスク表示で周囲の文字色を継承する。
- `static/images/`：時計の10種類の変化方向、既存サイズのブラウザ・端末アイコンを新しい図形から出力。
- `static/brand/icon-192.png` と `icon-512.png`：PWA用。新しいSVGをChromeで描画した画像であり、既存のビットマップを加工していない。
- `static/brand/care-connection.png`：Codex内蔵画像生成による、記録を見る人と医療スタッフの独自イラスト。ユーザー承認の代替ツールを使用した。選択できないImage2.5を使用したとは表記しない。生成済みの画像を確認し、そのままリポジトリへ複製している。

画像の作成目的は「白地と青を基調とする公共サービス向けの明快な線画で、スマートフォンを見る人、タブレットを見る医療スタッフ、両者をつなぐ血糖の推移を表す。政府のロゴや文字を入れない」。生成元のファイル名と使用ツールは `brand-assets.json` に記録した。

ヘッダーにはサービス名を常時表示する。元の `.customTitle` は本文上部に保持し、個別の表示名・警報・お知らせが従来のハンドラーで更新される。警報の判定、確認・停止時間、値、通信、アクセス権を変更しない。元のデザインとの比較用の変更一覧は `brand-source-plan.json` に固定し、ソース全体を逆変換で照合する。

支援技術による手動確認と人間のデザイン承認は、LPを含む最終状態の確認で実施する。
